# 🏝️ Treasure Island

## 📅 What I Built

Today I built a text-based adventure game called **Treasure Island**.

The player makes different choices throughout the game. Each choice leads to a different path, and the goal is to find the hidden treasure.

## 🧠 What I Learned

Today I learned:

- How to use `if`, `elif`, and `else`
- How to make decisions based on user input
- How to create different outcomes in a program
- How to build a simple text-based game
- How multiple conditions can create different paths

## 🛠️ Concepts Practiced

- `input()`
- `if / elif / else`
- Comparison operators
- Conditional logic
- Nested conditions
- User interaction

## 🎮 How It Works

The player is given choices at different stages of the game.

Depending on the choices made, the player can:

- Continue exploring
- Encounter obstacles
- Reach different endings
- Find the treasure 🏆

## 💭 Reflection

This project helped me understand how **conditional statements** can control the flow of a program.

It was also my first project where the user's choices could completely change what happens next.
