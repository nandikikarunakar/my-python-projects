# 🪙 Random Heads or Tails

## 📅 What I Built

Today I built a simple **Heads or Tails guessing game** using Python.

The program asks the user to guess whether the coin will land on Heads or Tails.
It then randomly chooses one of the two outcomes and checks whether the user's guess is correct.

## 🧠 What I Learned

Today I learned:

- How to use Python's `random` module
- How to generate a random choice using `random.choice()`
- How to take input from the user
- How to compare two values
- How to use `if` and `else` to create different outcomes
- How to build a simple guessing game

## 🛠️ Concepts Practiced

- `import`
- `random.choice()`
- `input()`
- Variables
- `if / else`
- Comparison operators
- f-strings

## 🎮 How It Works

1. The user guesses **Heads** or **Tails**.
2. The program randomly chooses Heads or Tails.
3. The program displays the result.
4. The user's guess is compared with the random result.
5. The program tells the user whether the guess was correct.
