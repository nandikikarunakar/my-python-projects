# 🔢 FizzBuzz

## 📅 What I Built

Today I built the classic **FizzBuzz** program using Python.

The program goes through the numbers from 1 to 100 and checks whether each number is divisible by 3, 5, or both.

- Divisible by 3 → `Fizz`
- Divisible by 5 → `Buzz`
- Divisible by both → `FizzBuzz`
- Otherwise → the number itself

## 🧠 What I Learned Today

Today I learned:

- How to use the modulo `%` operator to check divisibility
- How to combine multiple conditions using `and`
- How to use `range()` to generate a sequence of numbers
- How to apply multiple conditions in the correct order
- How to use a loop together with conditional logic
