# ✊ Rock Paper Scissors

## 📅 What I Built

Today I built a **Rock Paper Scissors** game using Python.

The player chooses Rock, Paper, or Scissors, and the computer randomly chooses one as well.
The program then compares both choices and determines the result.

## 🧠 What I Learned

Today I learned:

- How to use `random.choice()`
- How to work with lists
- How to take choices from the user
- How to compare different choices
- How to use conditional statements to determine the winner
- How to combine multiple Python concepts to build a game

## 🛠️ Concepts Practiced

- `input()`
- Lists
- `random.choice()`
- Variables
- `if / elif / else`
- Comparison operators
- Conditional logic

## 🎮 How It Works

1. The player chooses Rock, Paper, or Scissors.
2. The computer randomly selects its choice.
3. The program compares both choices.
4. The result is displayed:
   - Win
   - Lose
   - Draw

## 💭 Reflection

This project helped me understand how lists, randomness, user input, and conditional logic can work together to create a complete interactive game.

I'm starting to connect individual Python concepts and use them together in a single program.
