# 🔐 Password Generator

## 📅 What I Built

Today I built a **Password Generator** using Python.

The program asks how many letters, numbers, and symbols I want in my password.
It randomly selects the required characters, shuffles their order, and generates the final password.

## 🧠 What I Learned Today

Today I learned:

- How to use `random.shuffle()` to randomly rearrange items in a list
- How to build and work with a list of password characters
- How to use multiple `for` loops to generate different types of characters
- How to convert a list of characters into a final password string
- How to combine previously learned concepts to build a more complete program

## 🔑 How It Works

1. The user chooses the number of letters.
2. The user chooses the number of numbers.
3. The user chooses the number of symbols.
4. Random characters are selected from each list.
5. The selected characters are stored in a list.
6. The list is shuffled into a random order.
7. The characters are combined to create the final password.
