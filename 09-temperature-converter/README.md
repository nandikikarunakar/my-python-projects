# 🌡️ Temperature Converter

## 📅 What I Built

Today I built a **Temperature Converter** using Python.

The program allows the user to choose between two conversions:

- Celsius → Fahrenheit
- Fahrenheit → Celsius

It then takes the temperature as input, performs the conversion, and displays the result.

## 🧠 What I Learned Today

Today I learned:

- How to implement mathematical conversion formulas in Python
- How to handle decimal values using `float()`
- How to create a menu-based program
- How to connect user choices with different calculations
- How to handle invalid menu choices
